# n8n personal assistant

A personal assistant on self-hosted n8n. It reads Gmail, LinkedIn notification emails and
Telegram messages forwarded to a private bot, turns anything that needs attention into tasks
in Notion, prepares Gmail reply **drafts**, and sends a morning digest to Telegram with a
feasibility check against the calendar.

It never sends anything on the owner's behalf. It prepares, sorts and suggests.

## Layout

| Path | Purpose |
|---|---|
| `workflows/` | n8n workflow JSON, sanitized, generated by `npm run build` from the sources below |
| `prompts/` | Prompts and JSON schemas, one markdown file per prompt |
| `src/` | Code-node logic as pure ES modules, unit-tested in `tests/` |
| `config/` | `config.example.json` (committed) and `config.local.json` (gitignored) |
| `notion/schema.json` | Property definitions for the two Notion databases |
| `scripts/` | Build, deploy, export, safety check |
| `infra/` | Docker Compose (n8n + Caddy), install and backup scripts |

## Commands

```
npm test               # unit tests for src/
npm run build          # inject src/, prompts/ and config into workflows/*.json
npm run check          # no-send and privacy checks over workflows/*.json
npm run deploy -- WF1  # build + check + push one workflow to n8n via the public API
npm run export         # pull workflows from n8n, sanitize, write to workflows/
```

Node.js 20+, no dependencies. Scripts read `.env` (see `.env.example`). The Notion
databases are created from `notion/schema.json`; this repo does it with Claude Code's
Notion connector, but the schema works with any Notion API client.

## How the pieces fit

```
Gmail Trigger ──► WF1 Email Triage ──┐
                                     ├──► WF5 Decide ──► WF0 Upsert Item ──► Notion "Assistant Inbox"
Telegram bot ──► WF2 Telegram Intake ┘   (Jev | Haiku)                                │
                                                                                      ▼
Schedule 07:30 ──► WF3 Morning Planner ◄── Google Calendar (today)            reads open items
                        │
                        └──► Telegram digest + Notion "Daily digests" page
Any failure ──► WF4 Error Handler ──► Telegram alert
```
